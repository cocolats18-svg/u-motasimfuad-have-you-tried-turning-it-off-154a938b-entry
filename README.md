An entry for the [make.fun](https://make.fun) bounty **"Have You Tried Turning It Off?"** — one funny single-line reply from a hopeless tech support agent to a desperate customer.

## The line

> Have you tried turning it off and on again? I just did, and it fixed nothing — but it gave us both something to hope for.

The joke twists the classic "turn it off and on again": the agent cheerfully admits he tried it himself, it fixed nothing, and still offers it as shared hope. The customer's desperation is felt, never mocked — the agent's uselessness is the punchline.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no secrets, no dependencies — just Node 22.

```sh
node main.ts
```
